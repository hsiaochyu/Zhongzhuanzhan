# B260608 站 · 手机应用版——「探索 AI 世界」

## 为什么要做这个 App

前些天我们用 AI 搭了一批应用，可惜它们都住在聊天记录里——消息一刷，链接就被顶上去再也找不到了（校园论坛一直没人讨论，多半也是这个原因）。

与其在群里考古，不如把它们装进一个 App，点一下即达。

## 里面有什么

我们班用智能体搭建的各类网站，一站式直达：学搭子、活动管家、考勤助手、百事通、四六级、摄影展示、个人信息中心……不用记链接，不用翻聊天记录。

~~然而经同学反馈，真正做出来的app反倒没有人看，原作者自己编辑再把记录同步进聊天记录更方便。~~

App 本体：Kotlin + Jetpack Compose 编写，Android 8.0 及以上可装。

## 怎么拿到安装包

~~同学们的git基础有待提高啊...~~

你已经在仓库里了：右侧（或页面底部）**Releases** → 下载最新的 apk，装上就能用。

从聊天记录点过来的同学：去 GitHub 搜 **hsiaochyu** → follow 一下 → 仓库 **ZhongZhuanZhan** → Releases。

**遇到问题？**

- 登录不上 GitHub → 试试 Steam++：<https://steampp.net/>（拿你现成的游戏加速器顶上也行）
- 看不懂英文 → 浏览器装个「沉浸式翻译」插件；~~古法拍屏翻译也不是不行~~
- 懒得折腾 → 把这份 README 直接丢给 AI，让它带你把上面全程走完，你只负责点头
