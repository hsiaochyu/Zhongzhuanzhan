## 想一起做？零基础也能上手

不用会写 Kotlin，甚至不用装任何软件。三条路，从轻到重，挑一条就行。

**① 提一个需求（5 分钟）**

群里发一句话，或者到 Issues 点「New issue」，照这个格式写：

```
场景：我在____的时候用它
现状：现在会发生____
期望：我希望它变成____
```

> 例：场景——我在宿舍 WiFi 下打开学搭子；现状——白屏十几秒；期望——先给我一句「正在加载」。

**② 改一处错字（10 分钟，全程在浏览器）**

打开任意一个文档 → 右上角铅笔图标 → 改 → 底部写一句「修正错别字」→ 提交。

你刚刚走完了一次完整的 PR 流程，没有装任何东西。

**③ 指挥 AI 写代码（1 小时）**

把这段丢给任意 AI：

```
项目：Kotlin + Jetpack Compose 安卓 App
文件：app/src/main/java/com/zhongzhuanzhan/app/ui/MeScreen.kt
需求：在版本号下面加一行灰色小字「由 B260608 共建」，字号小一号
要求：只改这一个文件，给我完整的改动前后对比
```

把它给的改动贴进去、提交，验证交给构建。**你不需要看懂 Kotlin，只需要会提要求。**

想深入一点——自己打包、看架构、读代码 → [开发者手册](开发者手册.md)。
想了解下个大版本（认证整合）的计划 → [ROADMAP](ROADMAP.md)。
